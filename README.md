# 📊 MetricMind-AI

An AI-powered Business Intelligence Dashboard built using React, TypeScript, Node.js, Express, Axios, and Recharts.

---

## 🚀 Features

- 📈 Revenue Analytics Dashboard
- 📊 Sales Trend Visualization
- 🤖 AI Assistant Chat
- 💼 Business KPI Cards
- 📋 Recent Transactions
- 🎨 Modern Responsive UI

---

## 🛠 Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Axios
- Recharts

### Backend
- Node.js
- Express.js

---

## 📂 Project Structure

```
MetricMind-AI
├── frontend
│   ├── src
│   ├── components
│   └── charts
├── backend
└── dataset
```

---

## ▶️ Run the Project

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
node server.js
```
